# Reformes Clau · web de muestra

Web de muestra preparada por Nocodya para **Reformes Clau** (Claudio Ciuches, El Catllar, Tarragona): imitación de piedra, madera, hormigón y ladrillo visto con mortero tallado a mano, y reformas y albañilería.

- No es la web oficial del negocio.
- Las fotos y los vídeos son fotogramas y clips de su Instagram público (@reformas_clau); el logo es el suyo, calcado de su perfil.
- El formulario solo prepara un mensaje de WhatsApp: no guarda datos.
- Teléfono, zona, aviso legal, privacidad y dominio, por confirmar con el cliente.
